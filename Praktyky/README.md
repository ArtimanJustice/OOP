# Практики з ООП (C#)

Підсумкова робота за документом «Задачі на практики, ООП».
Рішення (.NET 8) у трьох проєктах, об'єднаних у `Praktyky.slnx`.

## Структура

| Проєкт | Що покриває | Тип |
|--------|-------------|-----|
| `Praktyka1-2` | Практика 1-2 (Основи C#): Завдання 1-4 | Консоль |
| `Praktyka3`   | Практика 3 (Класи): Завдання 3.1-3.3 | Консоль |
| `Praktyka4`   | Практика 4 (Форми): 2 програми | WinForms |

## Відповідність завдань і коду

### Praktyka1-2
- **Завдання 1** (цикли, патерни 1.1-1.19) — `Zavdannya1.cs`
- **Завдання 2** (одновимірні масиви 2.1-2.14) — `Zavdannya2.cs`
- **Завдання 3** (двовимірні масиви 3.1-3.4*) — `Zavdannya3.cs`
- **Завдання 4** (рядки 4.1-4.2) — `Zavdannya4.cs`

### Praktyka3
- **3.1** — клас `Stack` (масив, конструктори, Push/Pop, `Top`, `Length`, індексатор) — `Stack.cs`
- **3.2** — клас `Complex` (конструктори, ToString, Add(int), Add(Complex), Multiply, оператор `+`) — `Complex.cs`
- **3.3** — клас `Mult` з індексатором `[i, j]`, друк таблиці множення 10×10 — `Mult.cs`

### Praktyka4 (Форми)
- **Програма 1** — одновимірний масив: зворотний порядок, середнє, сортування — `ArrayForm.cs`
- **Програма 2** — рядок: кількість символу, кількість слів, позиція символу — `StringForm.cs`
- Головне вікно з вибором програми — `MainForm.cs`

## Запуск

```powershell
# зібрати все
dotnet build Praktyky.slnx

# запустити окремий проєкт
dotnet run --project Praktyka1-2
dotnet run --project Praktyka3
dotnet run --project Praktyka4
```

Консольні програми керуються текстовим меню (введіть номер пункту, Enter).
Форма запускається подвійним кліком по `Praktyka4.exe` або через `dotnet run`.
